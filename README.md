# Present Lab · מעבדת ההווה

פלטפורמת למידה מובנית לאנגלית (כיתות ז׳–ח׳): **Present Simple מול Present Progressive**.
המטרה: שהתלמידים יגיעו בהדרגה להפקה עצמאית של משפטים נכונים באנגלית — מתרגום משפת האם ועד כתיבה משלהם.

שפת העזרה (הוראות, משפטי מקור, תרגומי מילים, רמזים) ניתנת לבחירה: **עברית · רוסית · ערבית מדוברת (ירושלמית) · אנגלית בלבד**.
המורה קובע/ת שפת ברירת מחדל לכל תלמיד/ה, והתלמיד/ה יכול/ה להחליף בכל רגע.

**כל מה שנלמד בכיתה נלמד שוב באפליקציה — קודם מנחשים, אחר כך לומדים.** כל מיומנות שהמורה סימן/ה כנלמדה מופיעה בדף הבית כחזרה (ניחוש ← כלל ← דוגמאות ← בדיקה קצרה), וכל סט מילים שנלמד מופיע כחזרת מילים (מנחשים מה המילה אומרת ← רואים, שומעים, לומדים). גם בשיעור החדש: שלב "מילים" ושלב "מנחשים" באים לפני הסבר הכלל. ניחוש אף פעם לא נספר כטעות.

## שיעורים ארוכים (45–70 דקות)

| שיעור | חלקים (כל חלק = מיומנות אחת, נפתח רק כשהמיומנות סומנה כנלמדה) |
|---|---|
| **שיעור 1 · S, ing ו"עכשיו"** | חימום ← he/she/it + S ← הפסקה ← am/is/are ← פועל + ing ← הפסקה ← Present Progressive ← הפסקה ← עכשיו או בדרך כלל? ← כתיבה + כרטיס יציאה + אתגר בונוס |
| **שיעור 2 · שלילה ושאלות** | don't/doesn't ← isn't/aren't ← Do/Does? ← Am/Is/Are? ← שאלות מעורבות |
| **שיעור 3 · שאלות WH** | מילות שאלה ← WH + הווה פשוט ← WH + הווה מתמשך ← הרגל או עכשיו? |

- כל חלק: ניחוש ← כלל אחד (עם תמונת "בלוקים" לפני/אחרי, כמו במערכים בקנבה) ← דוגמאות ← בדיקה ← **שני סבבי תרגול** ← לפעמים כתיבה.
- הפסקות קצרות בין חלקים. הערכת זמן לכל שלב ולכל חלק ("כ-5 דק׳"), בלי שעון ספירה לאחור.
- בעמוד הלימוד: "📍 עברנו ← עכשיו ← הבא", ובצד רשימת החלקים — רק החלק הנוכחי פתוח.
- רמות קל/בינוני/מאתגר נבנות **אוטומטית** מכל משפט (`kind: 'sentence'`): בקל — בחירה ← בניית משפט ← השלמה, ותמיכה שיורדת לקראת סוף הסבב; בבינוני — בנייה והקלדה עם בנק מילים אופציונלי; במאתגר — תרגום ותיקון טעויות.
- סוגי תרגיל: בחירה, השלמה, בניית משפט, תרגום, זוג משפטים, תיקון טעות, שכתוב (לשלילה / לשאלה / ל"עכשיו"), מיון כרטיסים, התאמה, **אותו פועל – שני משפטים**, **צ'אט טלפון עם השלמות**, האזנה ובחירה, **מי? מה? איפה? מתי? ← משפט אחד**, כתיבה חופשית.
- הבודק מזהה גם: am/is/are חסר או שגוי, ing חסר, בחירת זמן, don't/doesn't, does + פועל עם S, isn't/aren't, Do/Does, Am/Is/Are בשאלה, שאלות WH. (`npm test` — 54 בדיקות.)
- `npm run validate-content` בודק גם ש**תשובת המודל של כל פריט מתקבלת בכל רמה**.
- בדיקה בלי לגעת בנתונים האמיתיים: `node test-server.cjs` מריץ עותק על פורט 5175 עם נתוני הדגמה זמניים.

## מה יש באב-טיפוס (פרוסה אנכית: He / she / it + S · טלפונים)

**תלמיד/ה:** כניסה בשם + קוד בלוח מקשים גדול · "איפה אנחנו?" (כבר למדנו / היום / בהמשך 🔒) · המשימה שלי · חזרות "נחש ← למד" · ההתקדמות שלי לפי מיומנות (זיהוי / כתיבה עם עזרה / כתיבה לבד), בלי דירוג · הודעות מהמורה · ארגז כלים דקדוקי בכל מסך (רק מה שנלמד פתוח) · לחיצה על כל מילה באנגלית: תרגום, הגדרה פשוטה, השמעה (לא נחשב כטעות).

**מבנה כל שיעור (קבוע וצפוי):**
מילים (מנחשים) ← מנחשים את הכלל ← לומדים ← דוגמאות ← בדיקה קצרה ← בוחרים כמות עזרה ← תרגול ← כותבים לבד ← כרטיס יציאה

**קל / בינוני / מאתגר** — אותה מטרה דקדוקית, פיגומים שונים:
- *קל:* בחירה (רק בין צורות שכבר נלמדו), השלמה עם הפועל בסוגריים, בניית משפט מאריחים, כלל גלוי, ובסוף תרגום עם בנק מילים (התמיכה יורדת לאורך התרגול).
- *בינוני:* בניית משפט ← הקלדת משפט שלם, פועל נתון, בנק מילים רק על פי בקשה (ונרשם כתמיכה).
- *מאתגר:* תרגום בלי עזרה, תיקון טעות, והשוואה בין שני משפטים (I / my brother · my friends / my friend). יותר חשיבה, לא דף ארוך יותר.

**משוב מדורג:** טעות 1 ← שאלה מכוונת ("הסתכלו על הנושא: She…") · טעות 2 ← הכלל על המילים של התלמיד/ה ("כתבת She use. עם She מוסיפים S") · טעות 3 ← תשובה נכונה + אפשרות להקליד אותה פעם אחת. אין אדום, אין "שגוי", אין טיימר.

**דקדוק ≠ כתיב ≠ אוצר מילים:** `My brother watchs videos` ← דקדוק ✓, כתיב ✗. `She looks her phone` ← דקדוק ✓, מילה אחרת מהמבוקש. מילה שהאפליקציה לא מכירה בכתיבה חופשית לא נחשבת טעות — היא מסומנת לבדיקת המורה.

**תיקון ממוקד:** אם אותה תגית שגיאה מופיעה ב-3 מתוך 5 התשובות האחרונות — 3 שאלות ממוקדות ואז חזרה למסלול. אף פעם לא ננעלים בגלל טעויות.

**כרטיס יציאה:** 2–4 משפטי תרגום, בלי רמות ובלי רמזים, ניסיון אחד. נשמר בנפרד — זה המדד הטוב ביותר לשליטה עצמאית.

**מורה:** סקירת כיתה (טבלת סטטוס לפי מיומנות + מגמות שגיאה לפי מושג) · כרטיס תלמיד/ה (ראיות לכל מיומנות, תשובות מקוריות / סופיות / מתוקנות, ניסיונות, רמזים, ארגז כלים, רמה, זמן, כרטיסי יציאה, סימון ידני כנכון, משוב שמגיע לתלמיד/ה, פתיחה מחדש ואיפוס) · יצירת תלמידים · שפת עזרה ורמת עזרה לכל תלמיד/ה · פתיחה/נעילה של מיומנויות + "היום" · עקיפה ידנית של דרישות קדם לתלמיד/ה · סימון סטים שלמים או מילים בודדות כנלמדו · הקצאת פעילויות · **תצוגה מקדימה Easy / Medium / Hard** עם הדקדוק, המילים ודרישות הקדם שנדרשים, ורשימת פריטים שמוסתרים כי דורשים חומר שלא נלמד · ספי שליטה ניתנים לשינוי.

**שליטה (Mastery)** — לא אחוז אחד. שלושה סוגי ראיות נפרדים (ברירת מחדל, ניתנים לשינוי): זיהוי 4/5 · הפקה עם תמיכה 3/4 · הפקה עצמאית 3 משפטים נכונים בניסיון ראשון, בלי רמזים ובלי בנק מילים.

### הוספת שיעור חדש (בלי לגעת ב-UI)
1. ליצור קובץ ב-`public/js/content/modules/` לפי המבנה של `third_person_s_phones.js` (מילים, ניחוש, כלל, דוגמאות, בדיקה, תרגול עם `difficultyConfig` לכל רמה, כתיבה, כרטיס יציאה, תיקון).
2. להוסיף אותו ל-`MODULE_LIST` ב-`content/index.js`.
3. להריץ `npm run validate-content`.

נושא חדש (דמוקרטיה / היסטוריה) = אותו מבנה עם `theme` אחר ומילים מהסט המתאים. סוג תרגיל חדש = מרנדר אחד ב-`ui/exercises.js` + מקרה אחד ב-`logic/score.js`.

## החלטות פדגוגיות שכדאי לדעת
- **בלי מסיחים מדקדוק שלא נלמד.** האפיון הציע `use / uses / is using`, אבל Present Progressive עוד נעול — לכן בשיעור הזה הבחירה היא רק `use / uses`. כשהמורה יפתח/תפתח את am/is/are ו-ing, אפשר יהיה להוסיף מסיחים כאלה בשיעורים הבאים.
- **ההיסטוריה בלי עבר:** הסט "היסטוריה 1" כבר קיים כנתונים (photo, document, hold, stand…) לשיעורים הבאים בתבניות כמו "This is a photo from 1963" / "People are standing" — לא נבנה עדיין שיעור שדורש Past Simple.
- **בנק המילים כולל את שתי צורות הפועל** (`use` וגם `uses`), כדי שההחלטה הדקדוקית תישאר אצל התלמיד/ה גם עם תמיכה.
- **תמונות:** כרגע אימוג׳י כתמיכה חזותית. אפשר להחליף בתמונות אמיתיות (שדה `image` / `situation`).

## מה עוד לא נבנה (בכוונה — קודם להוכיח את הארכיטקטורה)
- שאר 14 המיומנויות (העץ, הנעילה ותיבת הכלים כבר מוכנים להן).
- שיעורים בנושאי דמוקרטיה והיסטוריה ופרויקטי הסיום (Phone Habits, Democracy in Action, Historical Photo Detective).
- כניסה עם סיסמאות אמיתיות / חשבון מורה מרובה כיתות, ואחסון בענן. כרגע: שרת מקומי אחד לכיתה אחת.
- **תרגומים לרוסית ולערבית ירושלמית נכתבו על ידי AI — כדאי שדובר/ת שפת אם יעבור/תעבור עליהם לפני שימוש בכיתה.**
- השמעה משתמשת בקול האנגלי של הדפדפן (איכות משתנה בין מכשירים).
